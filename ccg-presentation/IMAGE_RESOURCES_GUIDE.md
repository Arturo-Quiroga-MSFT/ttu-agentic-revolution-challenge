## 🎨 **Image Best Practices**

### Resolution Guidelines:
- **Full-slide backgrounds**: 1920x1080px minimum (16:9 ratio)
- **Hero images**: 1280x720px minimum
- **Icons/accents**: 256x256px or 512x512px
- **QR codes**: 500x500px minimum
- **Logos**: Vector (SVG) preferred, or high-res PNG

### File Formats:
- **Photos**: JPG (smaller file size)
- **Graphics/Icons**: PNG (transparency support)
- **Logos**: SVG or PNG with transparency
- **Diagrams**: PNG or directly from Mermaid

### Color Adjustments:
- Use PowerPoint's "Recolor" feature to match Azure blue
- Apply 30-50% transparency for backgrounds
- Increase brightness for text readability

### Accessibility:
- Ensure sufficient contrast (text over images)
- Add alt text to all images (Insert → Alt Text)
- Don't rely solely on color to convey information

## ⚡ **Quick Tips for PowerPoint**

### Adding Images:
1. Insert → Pictures → Online Pictures (search directly in PowerPoint)
2. Or: Insert → Pictures → This Device (upload from computer)
3. Right-click image → Format Picture → Artistic Effects (apply styles)

### Background Images:
1. Right-click slide → Format Background
2. Picture or texture fill → Insert from file
3. Adjust transparency: 30-50% for readability

### Image Compression:
1. File → Compress Pictures
2. Select: "Apply to all pictures"
3. Resolution: "HD (330 ppi)" for presentation quality

### Alignment & Spacing:
1. Select multiple images → Arrange → Align
2. Use guides (View → Guides) for consistency
3. Alt + H + G → Show gridlines

## 💡 **Pro Designer Tips**

1. **Consistency is King**: Choose one illustration style (e.g., all unDraw or all Storyset) and stick with it
2. **Less is More**: 1-2 impactful images per slide beats 5 small icons
3. **White Space**: Don't fill every pixel—let content breathe
4. **Color Harmony**: Use color picker to extract colors from images and match to Azure blue
5. **Test Early**: View on projector/large screen before event day
